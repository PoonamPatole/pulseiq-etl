# PulseIQ Dashboard Style Guide

## Colour palette
- Navy: `#1F3864`
- Blue: `#2E75B6`
- Orange: `#C55A11`
- Green: `#548235`
- Grey: `#7F7F7F`

For good-versus-bad comparisons, use blue and orange. Never rely on red and green alone; always add a word or arrow.

## Fonts
Use Arial or Inter.

## Number formats
- Tables: full numbers.
- Headline tiles: lakh and crore, e.g. `₹ 5.55 Cr`.
- Percentages: one decimal place.

## Chart rules
- Every chart must have a clear title and a one-line takeaway based on real numbers.
- One question per dashboard; one message per chart.
- Prefer bar and line charts.
- No 3D charts; avoid crowded pie charts.
- Clearly label every AI chart as actual or predicted.

## Dashboard design
Use a clear visual hierarchy, readable labels, and layouts that work on laptop and mobile screens.
